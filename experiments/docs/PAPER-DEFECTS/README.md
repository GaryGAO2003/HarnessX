## 使用规则(重要)

### 1. 三档强度,不可混用

| 记号 | 含义 | 能不能直接写进论文 |
|---|---|---|
| 🔴 **论文自认** | 论文自己写了的(§7.7、Figure 4 标注、附录自述) | ✅ 可直接引,无争议 |
| 🟠 **文本可查** | 论文没承认,但原文摆在那里(矛盾、缺失、未定义) | ✅ 可引,需给页码 |
| 🟡 **我方推导/实测** | 我们算出来或跑出来的 | ⚠️ **必须与论文主张防火墙隔开**,不得写成"论文说" |

**最常见的错误是把 🟡 说成 🔴。** 例:"有效池 = min(K,簇数)" 是我方推导,
论文从不报簇数;"peak 偏差 +8.1pp" 是我方 Blom 估计,论文的 peak 膨胀自认
(Figure 4)是**定性的**。

### 2. 位置标注

📄 = 正文(§1–§8) · 📎 = 附录(A–E) · ⚡ = 正文与附录/图表互相打架

### 3. 动一条之前先查「已判死清单」

`novelty/09-SCORE-LEVERS.md §5` 有一份「勿回锅」清单。本表里已被判死的条目
标 ⛔ 并注明死因。**不要重新提议已死的方案** —— 这在 2026-08-04 已经发生过一次。

### 4. 引用论文时的两个技术 caveat

- **PDF 字体缺陷**:`fi/fl/ff` 连字在 PyMuPDF 和 poppler 下都被静默丢弃
  (`verifier`→`verier`、`flow`→`ow`、`efficiency`→`eciency`)。引用前重建,
  不要以为是转录错误。
- **Figures 5–12 未逐格 OCR**:只提取了 vector-text 标签。个别数值(如
  SWE-Qwen 的 0.05/0.05/0.06)是文本提取,**不是视觉验证**。Figure 4 已视觉核验。
