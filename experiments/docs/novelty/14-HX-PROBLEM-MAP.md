## 2. 第二层 · HX brainstorm（2026-08-06，按架构区域）

标注：〔已证〕= spec/代码/论文层已核验；〔待证〕= 架构推读，引用前须对代码核验。

### Compose 层（变异机器本身）

**HX-1 · 演化吞吐被桶封顶**〔已证〕compose 每桶每轮只收一枚 ⇒ 全环上限 4 编辑/轮（实际常 1）。
正交小修被迫排队或硬打包。瓶颈不在生成不在判定，在合成的类型系统。

**HX-2 · 三套坐标系互不映射**〔已证〕描述用 9 维、执行用 8 hook、演化用 4 桶，无映射。
自然编辑（hook 内 processor 重排、改 `_after` 依赖）在桶系统里没有家 ⇒ 整类行为空间因分类学不可达。

**HX-3 · 合法编辑面 ≪ 宣传编辑面**〔待证〕Table 1 每 hook 允许修改很窄（before_model 仅末条 user 消息/追加）。
processor 内部可任意写，processor **之间**的交互协议是死的。演化在走廊里爬。

### 环前半段（诊断链——此前火力全在后半段，这里是新地）

**HX-4 · 病理词表是冻结的先验**〔已证〕9 具名类 + other 逃生口，词表不在演化面内；
other 无下游消费者 ⇒ 词表外的病修不了，系统学不会新病类。诊断本体冻结 = 可修复病种冻结。

**HX-5 · 会诊由正则完成**〔已证〕每 Digester 只见本任务（读域最紧），跨任务聚合=digest 头部正则解析。
"六任务同根因"没有组件有视野看见 ⇒ 一个根因修六遍或永不修到。

**HX-6 · 处方从传闻里开出**〔已证〕Planner 禁下处方、Evolver 唯一战略输入是 landscape.md ⇒
治疗者从不接触原始证据，材料是"摘要的摘要的转述"；反向通道仅 ask_evolver（≤2 次，问的还是提案者本人）。
防锚定的故意设计，但候选质量天花板被压在转述质量上。

**HX-7 · actionability 是四档硬楼梯**〔已证〕1.0/0.8/0.3/0.0 决定整轮 meta 预算花不花；
"103 题同根因"与"6 题各自翻车"同记 1.0。最贵开关只有两比特分辨率。

### 池与谱系（变体隔离）

**HX-8 · 谱系有 fork 无 merge**〔已证·架构层〕变体分叉后完全隔离，A 的修复无通道传给 B——
进化只剩分裂算子。87.4 headline 依赖的池，机制上是 N 条互相失明的单谱系。
（fork 判据太松已另案：fork 净支配，挂 N-10 之下，见 00 §4——本条说的是**拓扑缺算子**，不同病。）

**HX-9 · 池核心参数未定义**〔已证·论文层〕容量 K 正文无数值、簇形成未定义、退役="满退最差"（又是噪声选择）。
最好的实验结果坐在最欠规格的机制上。

### 数据资产层

**HX-10 · 历史轨迹是已付费未消费的资产**〔已证〕trace store 单调累积，除 counterfactual 抽上轮 3 条外
零消费。每份证据都要新 rollout 去挣，千万 token 历史躺账 ⇒ 证据复用率≈0，新假设不能拿历史免费预审。
环里最大一笔沉睡资产。

### 协议与起点

**HX-11 · 演化锁死在 H₀ 山头**〔已证·论文层〕冷启动=已经能打的手工组合（§A.4），
摘要自认 gains largest where baselines lowest。无"换座山"机制，盆地之外不可达。

**HX-12 · 逐任务预算是全局常数**〔已证〕max_steps/max_cost 一刀切：长任务饿死
（budget_starvation 恰是九类病理之一——病在自己词表里，病因在自己协议里），短任务浪费。
"按任务分配预算"这个行为维度存在于 harness，却不在演化面上。

**HX-13 · 评判组件在编辑面内**〔待证〕D6（evaluate）是九维之一；config 桶能否触到 verifier/reward
配置未核验。若能：环存在自我奖励改写通道——不需恶意，只需一次"顺手调宽判定"的 ship。
判者与被判者间无保护边界。

**HX-14 · D9 桥继承 G5 血统**〔已证·架构层〕协同演化 reward 来自同一 in-sample verifier ⇒
模型微调不是逃出闭环的路，而是把闭环偏差蒸馏进权重的路。
