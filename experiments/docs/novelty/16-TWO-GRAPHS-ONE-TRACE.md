## 0. 统一主张

harness 每次运行只产出一份权威事实——trace。两张图都是它的衍生物：
微观图（GS）在 run 内在线建、在线消费；宏观图（IR）跨轮持久、在 run 之间消费。
融合主张：**两图经一次投影 π 相连后，宏观层每个吃 trace 的机制都从"平铺足迹"
升级为"结构化切片"，微观层的承重墙（边可信度）获得宏观层已设计的收口方案。
拆开各自成立，合上互为供给。**

## 1. 投影 π 的定义与它的一个陷阱

π: GS 图节点（步/实体）→ IR 节点（组件/processor/skill）。
步 s 映到"在 s 上**实际起作用**的组件集"——hook 触发且改写了事件/贡献了内容的组件，
不是全部注册组件。

**陷阱**：不带活跃判据的朴素投影会把每一步映到整条 pipeline，足迹密度 → 1，
选择性重测的交集稀疏性（v2 的核心收益）直接归零。活跃判据是 π 的承重件。

**S0 核验（2026-08-07，代码已查）**：活跃判据**部分已可得，强于预期**。
ProcessorChain 在链中逐 processor 自动发射 `processor_trigger`
（processor.py:455-466 → journal.py:1116-1134），当且仅当 primary 事件被改写，
携带 processor 类名 + hook + step——正是活跃判据的直接命中。三处硬缺口：
1. **拦截型不记**：yield 空的阻断在早返回（processor.py:438-439）先于发射，
   按判据活跃却无记录；
2. **compare=False 字段隐形**：只改 skip_model / synthetic_output / boundary_hint
   的干预不触发 diff（events.py:119-137）；
3. **同 (hook, step) 多 processor 不可拆分**：trace 知道"谁们"干预了，
   `.jsonl` 只有一条最终 delta，改动无法归属到个体（detail 恒空，全包无手动发射）。

最小补丁单点：发射块填真实 diff + 早返回前补拦截记录 + 视需放宽 `_diff_primary`。
**历史 trace〔已坐实，2026-08-07 抽查〕**：organic1 与 a1big5 两 run 的
`*_trace.jsonl` 均含 `processor_trigger` 记录，字段与代码分析一致
（processor 名 + hook + step；action 恒 "intervention"、detail 恒空——三缺口
形态亦获实证）。存量 trace 约 1.2 万份，②⑦ 可直接离线计算，无需等补丁。

**π 的边诱导规则**（v3.1 补，此前只定义了节点映射）：
- **观测数据边**：GS def-use 边 (i →ₑ j) 诱导 IR 数据边——从 i 上的活跃组件
  （写侧）连到 j 上的活跃组件（读侧），标注实体类 e；执行工具的步恒以该 tool
  节点为写/读侧成员。
- **多活跃降级**：同侧 ≥2 个活跃组件时（缺口 3 场景）取叉积、边权
  1/(|W_i|·|R_j|)；跨步跨 run 聚合权重，对账只吃过阈观测边。单活跃（常态）即权重 1。
- **观测控制边**：拦截 / skip 类干预诱导控制边（组件闸了流）。缺口 1/2 补丁
  落地前控制边不可观测——对账的"缺席"类在控制边上暂不可判，**明记为盲区**，
  不默认收敛。

## 2. 融合增量（超出两侧并集的部分）

**Δ1 足迹 → 切片足迹**：任务足迹从"触过的组件"收窄为"在最终输出反向切片上的组件"
（π∘GS-C）。足迹更稀疏 ⇒ 危险边集 × 足迹交集更小 ⇒ 选择性重测省得更多。
动的数字：每轮评测调用数（v2 §3 同一格，上限抬高）。落 S5。
**排期挂 S2⑥**：切片稳定度过线才实施；不过线则 Δ1 降级回足迹并集档
（v2 路线），S5 照走，其余 Δ 不受牵连。

**Δ2 可疑度加权**：Tarantula 式失败相关性从"组件被触碰"升级为"组件在失败输出的
切片上"。失败聚类更锐 ⇒ failure_density 选靶精度。落 S4。

**Δ3 确定性风险的第三条收口**：v2 风险 2 原是二选一（确定化回放 / 足迹并集）。
切片给出第三条：**切片并集**——主张切片比原始足迹跨随机执行更稳定
（切片捕捉任务的数据流核心、剥离偶发探索）。若同任务多次执行走真正不同的数据流路线，
此主张失效——S2 离线可测（切片稳定度）。落 S2。

**Δ4 双层信用分配对 HL4**：宏观归因（哪条编辑）与微观归因（哪些步）是同一问题的
两个粒度，π 把它们连成一致性约束：一条 config 编辑的效果应显形于该 config 下
runs 的切片分布变化。HL4 的三粒度错位由此获得两级结构化答案（编辑级 × 步级），
中间粒度（轮/桶）由投影桥接。落 S5/S7。

**Δ5 声明边先验反哺微观**：IR 的声明边（哪类工具写哪类实体）作为 GS 实体抽取的
先验；观测 def-use 边经 π 回来与声明对账，反射三分类（收敛/发散/缺席）同时在
两层运行。GS 的承重墙（抽取召回）获得声明先验兜底 + 对账自诊断。落 S3/S4。

**Δ6 训练记录双坐标**：to_training_records 每步同时携带微观坐标（切片 reward，
GS-C）与宏观坐标（genotype 哈希，S1）。轨迹采集产物从"平铺步 + 常数 reward"
变为两层结构都在场的 RL 数据——正中 HarnessX 作为训练轨迹采集器的定位。落 S4。

### 第二批（Δ7–Δ13）：08-07 定向扫先例的机制吸收（F2：全部点名 + 写明变步）

**Δ7 类型词表与 BOM（← AgentFlow/ADG 2607.01640）**：IR 类型系统以 ADG 词表
起步（节点 agents/prompts/models/tools/memory/control-policy；边 依赖/控制/数据流），
叠加我们的声明/观测轴。变步：ADG 从既有框架**恢复只读图**做审计，我们把同一
词表升为**可编辑组合契约**的类型系统；顺带免费产出 Harness BOM 与 prompt→tool
污点检查（验证器附加 pass）。落 S3。

**Δ8 hook 生命周期 DFA 验证（← Agentproof 2603.20356）**：8-hook 生命周期本身
是自动机；build 验证新增"候选图 × 生命周期 DFA 乘积"pass，拦结构合法但协议
违规的候选（如依赖方向与 hook 时序矛盾的 `_after` 声明）。变步：Agentproof 验
workflow 图对外部规约，我们验组合图对 harness 自身 hook 契约。动的数字：S2①
跑前拦截率上限。落 S3。

**Δ9 声明需引证（← SIGIL 2607.27309）**：声明边必须携带出处（代码 file:line 或
观测边证据 id）；无证声明只进检索不进验证器。变步：SIGIL 的 compile gate 管
skill 规则对原文引用，我们管声明边对代码/trace 证据。增益：对账"缺席"类可直接
指认无证声明，LLM 起草的声明层污染不扩散。落 S3。

**Δ10 图编辑的文本面 + 有效率锚点（← MermaidFlow 2505.22967）**：演化层 LLM 以
可静态校验的文本图语法提交图编辑（提交面是文本，落地前过 build）；"提案有效率"
（编辑过验证比例）立为 S2/S7 指标，公开锚点 AFlow ~50% / MermaidFlow >90%。
变步：它验整张每任务 workflow 图，我们验组合层图编辑且**增量**重验。落 S5/S7。

**Δ11 实体抽取三层防御 + 行号回链（← AgentGraph AAAI-26 demo）**：承重墙加固为
三层——确定性抽取（主）→ 声明先验（Δ5）→ **schema 约束 LLM 软边抽取（兜底）**；
软边只进检索与驱逐排序，**永不进验证器与切片**（沿用硬/软边权限划分）。另收编
trace 行号回链：GS/IR 图元 ↔ journal JSONL 行/uuid 双向链。变步：AgentGraph 用
LLM 抽整张图，我们只让 LLM 补确定性抽取的漏、且强制降级为软边。落 S4/S4G。

**Δ12 GS-B 第三级冗余确认（← George et al. 2511.10650 的 CDSA）**：GS-B 自认
漏报（每轮写新实体的空转）以输出相似度补：SCC 候选 → 进展判据 → **仅当
"有新写出且输出近重复"时**触发语义确认。变步：CDSA 离线全量确认调用栈候选，
我们在线、窄分支触发、成本有界。动的数字：GS-B 对追加日志式卡死的召回。
落 S4G。（同步记入 15 号 GS-B。）

**Δ13 观测边双时态失效（← Zep/Graphiti 2501.13956）**：观测边带 valid-time，被
新观测矛盾时失效不删除；对账的发散/缺席在失效史上算，腐蚀度斜率获得确定性
底层机制。变步：Zep 用于对话记忆图，我们用于架构观测边。落 S4。

**有意不吸收**：GBC（2606.28187）的 token 级影响权重——梯度式软权与确定性边权
体系冲突，且只服务固定拓扑调参；HarnessForge / NLAH 定位为对手非供体（§5）。

### 第三批（Δ14–Δ17）：补洞批（08-07 深读后，用户已确认）

**Δ14 Owner Test 定 IR 边界（← SIGIL 2607.27309）**：IR 此前没有"图到哪里为止"
的判据；采 Owner Test——"该步输出是否为其输入的函数"：是 = code-owned，入图为
结构节点；否 = model-owned，只作类型化槽位、不图化内部。变步：SIGIL 用它切单个
skill 的编译边界，我们用它切整个组合层 IR 的建模范围——防止 IR 膨胀到把模型行为
图化（那会毁掉验证的可判性）。落 S3（声明补全之前先划界）。

**Δ15 跨 spawn 切片（← Horwitz-Reps-Binkley TOPLAS 1990 过程间切片；对照
GraphGPO/Liu 均不跨 agent 边界）**：GS 图经共享 workspace 实体跨父子轨迹连边
（子写文件 → 父读文件 = 跨边界 def-use）；spawn 视作调用点、子轨迹视作过程、
workspace 实体流即摘要边——GS-C 反向切片穿进子代理，reward 流到子步。变步：
过程间切片的"过程"从函数换成 subagent 轨迹。动的数字：多代理任务训练记录中
子代理步的 reward 列从无信用变切片信用；2026 两篇归因先例均单轨迹，此格空。
落 S4/S4G（建图跨 spawn）。

**Δ16 表型哈希 = GS 图规范化哈希（← Build Systems à la Carte ICFP 2018 / Nix
的 early cutoff）**：v2 的 phenotype 哈希此前无具体定义；定义为同任务 run 的
GS 图规范化哈希——步有全序、实体有名，是标号图，线性可算、无一般图同构问题。
两候选行为等价 = GS 图同构 → 跳测/去重的第二把钥匙（与 π 互补的又一根
micro↔macro 连线：π 连组件，表型哈希连行为）。变步：early cutoff 的等价判据从
"输出字节相等"换成"执行结构同构"。动的数字：S2③ 重复候选率上限（行为级重复
⊇ 结构级重复）。落 S1（哈希）+ S5（跳测）。

**Δ17 声明层自举（← AgentFlow 2607.01640 静态前端）**：AgentFlow 式静态分析
（无 LLM，59/60 成功率先例）跑在 harnessx 自身代码上，自动产出带 file:line
引证的种子声明——引证直接满足 Δ9 引证门。变步：它分析他人 agent 程序产只读
审计图，我们分析自身产可演化 IR 的种子声明层。消掉 v2 风险条目"种子声明层
为空的前置成本"。落 S3。

**随批三条非 Δ 记录**：① related work 对应句——Agentproof 的"反向可达/出口
可达"是 GS-C/GS-A 的离线静态版（18 号）；② S6 实现直接采 GoS 参数面
（reverse-aware PPR α=0.2、双预算注水 2400/12000 字符、top-8）+ SkillDAG 治理
内核（5 边类 + 三不变式 + propose→commit）；③ **TMS-lite 叙事钉**——Δ9 + Δ13 +
声明↔观测对账合起来构成 justification + retract 的轻量真值维护，正面回应内部
问题图 HL5 的"TMS/AGM 空白"（14 号 §1）。

## 4. 若融合是错的，错在哪条假设

1. ~~π 的活跃判据不可得~~ **S0 已核验 + 存量 trace 已抽查坐实**（processor_trigger
   带名带钩带步，organic1/a1big5 均含；三缺口 + 单点补丁见 §1）。此假设**退役**——
   残余仅三缺口影响 π 的精度（漏拦截型、漏 compare=False、同钩多 processor
   不可拆分），不影响可得性；②⑦ 直接在存量 trace 上算；
2. **切片跨随机执行不稳定**（Δ3 主张的反例）⇒ 微观层仍成立，但对宏观选测的
   供给失效，退回足迹并集；
3. **实体抽取召回不足且声明先验兜不住**（Δ5 失效）⇒ 15 号 §3 反面自查指认的
   共同失效点，两层一起塌回 v2 原状。

三条都有 S2 离线可测形态，全部零 API。
