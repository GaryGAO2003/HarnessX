## 3. D1 · Matrix 统计层

### 3.1 数据与切段

- 输入:`pool_state.active_pool_measurements` 逐轮(pass@2 任一过 = 1),**剔除 `active_score_source == "candidate_reuse"` 的 cell**(in-sample)。只读派生,不新增持久化(可选 debug dump)。
- **纪元** = 该变体两次被 ship(APPLY/FORK 转正)之间的轮段。断点从决策日志读,**不需要变点检测**。更早纪元的数据只用于 Tier B/C 区分,不混入当前估计(免衰减超参)。

### 3.2 统计量与四类

Wilson 下界(z = 1.28,申报超参):

```
LB = [ p̂ + z²/2n − z·√( p̂(1−p̂)/n + z²/4n² ) ] / (1 + z²/n)
```

| 类 | 判定(当前纪元) | 消费方式 |
|---|---|---|
| PROTECTED | LB ≥ 0.5(7 轮纪元约需 ≥6/7;2/2 即 LB=0.55 可达) | 回退义务 |
| Tier A | k ≥ 1 且非保护 | 首选目标(harness 敏感,可稳定化) |
| Tier B | 本纪元 k=0,但本变体早期纪元或**其他变体**解出过 | 次选,brief 附配方指针 |
| Tier C | 任何变体任何纪元都没解出过 | 能力疑难,降优先级 |

### 3.3 真实数据产出(亲验)

- R12 开局:V0(纪元2,n=3)PROT 34 / A 5;V1(n=9)PROT 41 / A 19 / C 4。
- 现行规则给 V1 的可改进池 = 4 道,**恰好全是 Tier C 死题**;19 道活题不可见——优先级是反的。
- `c365c1c7` 从"挡整轮的义务"变为 Tier A 目标;虚义务 V0 39→37、V1 60→52。
- 阈值敏感:同数据下 3-of-6 给 V0 池 2、纪元 Wilson 给 5 —— **阈值必须入 lock 申报**。

## 4. D2 · 分预算(F-ALL)

### 4.1 合法性

§4.5 原文按**候选**说话("a candidate targeting variant k"),从未要求一轮共享单目标;"每轮单目标"是我方收窄(M-16)。附录 B.1 明写 bucket-disjoint 可同轮多发(#33/M-17);落盘 schema 本就是字典形(`decisions`/`per_variant_pass`/`pipeline_audit_paths`),lock 已写 `candidates_per_round = "global_up_to_4"`。

### 4.2 规则

```
s_v      = |Tier A(v)| + |Tier B(v)|
slots_v  = K_t · s_v / Σs,最大余数法取整,平局低 id
排除     : 试用期中的变体、冷却期中的变体(§4.7)
地板     : s_v>0 的变体每 3 轮至少 1 槽
```

**必须零随机**(resume 哈希纪律)。算例:R9 状态 s(V0)=5、s(V1)=14 → 1+3(实跑为 4+0)。

### 4.3 Planner 输入升级

brief 从原始 digests 换成排序目标清单:Tier A 附翻转序列(如 `676e5e31 110110110`),Tier B 附配方指针("V0 R0 配置解出过"),Tier C 标注勿投入。纯 prompt 侧,零架构成本。

### 4.4 成本

门测 rollouts = Σ slots_v·|T_k(v)|·2。分预算版对照单目标 ≈ +30–50% 门测;真跑每轮大头是活跃池评测(206 次,两侧相同),**整轮 ≈ 1.3–1.5×**。

### 4.5 v2(暂缓)

槽位回报 EWMA 跟踪(SEC 的 TD 完全体)。v1 免超参优先。

## 5. D3 · 路由(方差意识 + 滞回 + 钉回 + 补集)

### 5.1 换手规则

```
在位者 i = 当前簇内持题最多的变体(平局低 id)
挑战者 j 夺簇 ⇔ WilsonLB_j(当前纪元簇内合并计数) > p̂_i + δ,δ = 0.05
```

不对称即滞回:在位按点估计站,挑战按下界弯腰 —— 样本少、方差大自动矮一头。

### 5.2 新生入场(F2,分支已实现)

`--record-gate-complement`(fix/novelty-s3 `e8d3541`)把 fork 丢弃的门测补集补记给子代 → 子代入场即有 n=78/104/24 级别的诚实计数,下界有东西可算。**依赖约束:F2 不得单开**(亲验:单开则 V1 通吃 103 题——单轮新鲜测量 + 点估计 argmax 的过矫正)。

### 5.3 R3 冻结重放(亲验)

```

L1      0.806(232)        0.833( 78)          0.772    0.856    V0 守住
L2      0.537(294)        0.740(104)          0.682    0.587    V1 夺走
```

### 5.4 F5 · 回退题按题钉回

## 6. D4 · 门(接受判定)

### 6.1 判定量重定义

```
improved  = 翻正一道非 PROTECTED 题(替代"历来从未通过")
regressed = 打掉一道 PROTECTED 题(替代 ever_solved 棘轮)
```

打掉一道 5/9 摇摆题**不算回退**(未达保护线)——虚义务消失。⚠️ regressed 侧动了论文明文规则(§4.1 `T_t` 单调),**CH4 改进臂,须申报**;improved 侧本就是我方留白自填,换填法仅需声明。

### 6.2 试用期(v1,首臂用)

```
第 r 轮    候选过五道静态检查(不变)→ 临时 ship,记 pre 状态
第 r+1 轮  新配置的新鲜结算测量 vs ship 前纪元:
           PROTECTED 通过率跌幅 > 15pp(申报超参)→ 回滚(manifest rollback 靶,
           论文自带机制,🟢 亲验存在:p.10 Evolver 每候选携带 manifest/§7.6 回滚靶)
           否则 → 转正,开新纪元
试用期内   该变体槽位 = 0(防混淆)
```

选择与计分的测量从机制上分开 → winner's curse 无处发生(fork 子代同理:入场账本 = F2 播种,转正凭下一轮自己的新鲜成绩)。

**代价申报**:转正晚 1 轮、同预算 ship 减少——吞吐换判定有效性。

### 6.3 v2(门侧专项臂)

PACE 式 testing-by-betting(🟡 2606.08106:配对胜负驱动财富 `E ← E·(1+λ(2w−1))`,`E ≥ 1/α` 转正,anytime-valid)。首臂不上;若上,PACE 全文须先主循环精读。

### 6.4 idle 语义

临时 ship 即清零(有活动不算空转;与 `engine.py:471` 现行"任一 ship 清零"一致)。

## 7. D5 · 结算与三条承重规则

### 7.1 纪元重置

转正的 APPLY/FORK 给该变体开新纪元:统计重启,`prev_prot` 存档,Tier 重算。`variant_id` 仍是血统(不动数据结构),"血统 ≠ 配置"在统计层化解。**子代的纪元起点 = 门测所在轮**(其 F2 播种计数属于新纪元——模拟 v3 教训:记在纪元外则子代路由永远赢不了,改进困死)。

### 7.2 三条承重规则(模拟逐版抓出;实现时任何一条都不可省)

| 规则 | 内容 | 省掉它的实测后果(模拟) |
|---|---|---|
| **R-桥接** | 新纪元头 2 轮,上一纪元 PROTECTED 继续生效 | v1:每轮 ship、门成橡皮图章、池被稳定题灌满,16 轮零收益 |
| **R-冷却** | 纪元不满 2 轮的变体不许再被演化(= SMAC intensification:在位者先积累证据) | v2:纪元永远 1 轮长,保护永远建立不起来,同 v1 |
| **R-fork 保守化** | 既然 APPLY 可回滚,仅当 `|regressed| > 2 + 0.05·|PROT|`(噪声带,申报超参)才 FORK,否则视作临时 APPLY 交试用期裁决 | v3:30+ 保护题单测按噪声必掉几道 → regressed 恒真 → 7 fork 0 apply(**论文 P3 病在新方法里复活**),改进困死在无人路由的子变体,部署真值跌回起点 |

## 8. 旗标与申报

| 旗标 | 默认 | 控制 | 依赖约束 |
|---|---|---|---|
| `--evolve-targets single\|all` | single | D2 | 开启时 R-冷却自动生效 |
| `--ledger-stats legacy\|matrix` | legacy | D1 + D4 判定量 | 开启时 R-桥接自动生效 |
| `--routing-score laplace\|wilson_lb` | laplace | D3 换手 | — |
| `--routing-hysteresis <δ>` | 0 | D3 | 需 wilson_lb |
| `--record-gate-complement` | off(已在 `e8d3541`) | D3 新生 | **必须与 wilson_lb+hysteresis 同开** |
| `--pin-regressed <k>` | 0 | F5 | — |
