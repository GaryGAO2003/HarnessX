## 选型结论（一页）

### 1. 五个候选机制**全部是成熟标准技术**

外证齐备（`03`）：archive/elitism、bandit 探索、racing 式统计接受、island/niching、算子自适应选择——每一条都有已发表效应量，**我们不需要为 novelty 辩护，只需要诚实报增量**。这正是"克制改进"的立论基础。

### 2. 先做 Tier 0（四条，零跑动）

在**已落盘日志上做反事实重放**：同一批 rollout，换一个门控/部署策略。**没有重新采样 ⇒ 没有 4.6pp 的重测噪声。**
⚠ 但有硬边界（`02 §2`）：**只有"不改变 agent 后续生成/观测"的纯 re-scoring 才精确有效**；会造成轨迹分叉的策略必须真跑。

### 3. ⚠ 第一轮探针推翻了两条我们自己的判断

| v1 判断 | 实测 | 修订 |
|---|---|---|
| 精英保留是"最稳的一招" | s1k8b103 的 peak−final = **+5.8pp**，而 15 轮纯噪声期望是 **7–8pp** | **朴素 best-so-far 是噪声追逐**；可辩护形态是 **δ-阈值冠军**或 Pareto 前沿。预期收益很小 |
| 有效池容量被簇数封顶（≤3），K=8 不可达 | s1k8b103 **确实创建 8 个变体**，逐轮在册最高 **4>3** | 作废。改为：**池创建得出多样性但留不住**——V0 覆盖 99/103 且 16 轮全在册，7 个 fork 全是短命挑战者，**零 retire**。持久多样性 ≈1 |

第二条尤其重要：**它关系到 N1"持久演化池"主张的前件是否成立**，写论文前必须查清。

### 5. 预算不是瓶颈，配对才是

✅ **A/A 空校准不必再跑了（2026-08-04）**：`e_pervar3` 自带——它 14 轮里只上线 2 次，其余轮是
两个静态配置的纯重测。按"未上线 **且** 路由分区逐字节相同"切 epoch（`h_config_epoch_curve.py`），
得 n=2/5/6 三个 epoch，**合并组内 SD = 3.18pp（df=10）**。这就是本床的噪声地板。

非配对双臂、80% 功效、α=.05：

| 目标效应 | 每臂轮数 |
|---|---|
| 2pp | 40 |
| **3pp** | **18** |
| 4pp | 10 |

配对 + 同窗交错可再降（原估 σ_D 6.5→3.8 ⇒ ~13 轮），但 **3.8 是假设值，18 轮是实测上界**，
排期按 18 走。
⚠ 固定 seed 几乎不省方差——逐字节相同重测仍翻 **33% 的题（n=5 窗口；n=3 时为 23%，
该比率不是 n-不变量，引用必须带 n）**。能锁的是全局分量，办法只有同窗交错。
⚠ **s1k8b103 不能用于此估计**：它的路由几乎每轮都变（`freeze_routing` 每轮重跑 argmax），
即使没上线也不是同配置重测。
