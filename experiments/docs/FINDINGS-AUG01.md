### B-1 · 可利用互补性 = 零
> 🔴 **读数前先读上面的撤回块。** 数字有效,因果解释无效。
交叉拟合（奇数轮选、偶数轮评）+ 200 次置换零假设，64 道充分覆盖的题：

| | |
|---|---|
| 最强单一变体 V7 | **0.656** |
| 逐题 oracle 路由 | 0.615 |
| **头寸空间** | **−0.042** |
| 置换零分布 | mean −0.041 / p95 +0.023 |
| **p** | **0.530** |

**观测值等于零分布均值 ⇒ 确认不存在，非「测不出」。**
（变体间分歧率 0.237 vs 同变体自身 0.115 —— 分歧真实，但方向单一，是强度阶梯。）

> ### 🔴 适用范围限定（务必随该数字一起引用）
> **本测量的对象是「整题路由」的互补性，不是变体池的一般性判决。**
>
> 每道整题都是能力的混合体（L2/L3 平均 **2.27** 种能力，81% 需要 ≥2 种）。
> 所有变体面对的是**同一种混合**，各自的强项在混合内被平均掉 —— 零互补是这个粒度的必然结果，
> **不能推断为「变体之间没有可用差异」**。
>
> **正确的读法**：整题粒度看不见变体差异 ⇒ **这正是任务分解的动机**。
> 子任务是单能力的；一个在检索上更强的变体，只有拿到检索子任务时才显得出来。
>
> **由此产生的核心预言（可用同一把尺检验）**：
> **子任务粒度的可利用互补性 > 整题粒度的互补性（= 0）。**
> 两个粒度各量一次，即本论文最硬的对比。

## F. 三臂阶梯（每层归因给一个部件）

| 臂 | 内容 | 隔离出什么 |
|---|---|---|
| **A** | `max_steps=60`，**不分解** | 纯预算的贡献 |
| **B** | 分解，**单一变体** | **分段**的贡献（A→B） |
| **C** | 分解 + **子任务路由到变体池** | **变体池**的贡献（B→C） |

**总步数预算在三臂间匹配**，否则「分解有用」会被读成「你多给了算力」。

**C vs B 即「变体池到底值不值」** —— 这一问只有在池子存在的前提下才提得出来，
因此 CH3 的复现是 CH4 的**承重件**，不是前置背景。
