## T1 · 免费分析(零额外模型调用,全部从已落盘产物算)

### A. 噪声地板实测 ★最高价值
**做什么**:取所有**无 ship 轮**(配置未变,轮间差纯属测量噪声)的 Δpass@2 分布,
给出经验噪声带(均值/SD/绝对值分位数)。现有样本 ≥6 轮(R3/R5/R8/R9/R10/R12)。
**为什么值钱**:M-25 现在是"抄论文 Table 8 的 ±5%";这一步把它换成**我方环境自测值**。
若实测远大于 5%(初步迹象:无 ship 轮摆动达 ±8pp),则论文所有判读阈值都要按实测重设。
**进论文**:ch3 判读规则(把 M-25 从 [PAPER] 改成 [OURS,实测])+ ch7 威胁章
**限制**:无 ship 轮的路由仍会变(领地重分配),故这是"配置恒定但路由自由"的噪声,
是我们真正关心的量,但须如此措辞——不是纯重放噪声。

### B. 路由上限(best-of-pool ceiling)★决定 B 臂预期
**做什么**:跨轮取并集——任一变体在任一轮解出过的题集合(= 门用的 `is_ever_solved`),
除以 103。与末轮实际分对比 = **路由损失**。
**为什么值钱**:B2 的全部空间就是这个损失。损失大 ⇒ 分工有搞头;损失小 ⇒ 天花板低,
**在花钱跑 B 臂之前就知道**。
**进论文**:ch6 结果 + ch4 动机
**限制**:每轮只测被路由到的变体,故这是"曾被解出"的**乐观上限**,不等于"当前任一变体可解";
须明确标注,且不可称因果。

### C. 事后最优路由回放
**做什么**:每题按跨轮历史记录派给成功率最高的变体,估计"完美路由"分数。
与 B 的差别:B 是乐观上限,C 是**可实现策略**的估计。
**进论文**:ch6(与 B2 实测对照)
**限制**:同 B 的观测偏差 + 事后选择偏差,只作参照不作主张。

### D. 协议停点重建(p3 / p5 / p8 / p16)
**做什么**:一跑内重建多种 patience 协议的停点与终值。p3 已知 = R10(60.2%)。
**为什么值钱**:直接结掉 ch3 那个 `[ADJUDICATION-PENDING: S1 patience]`,并给出
"**论文 verbatim 协议在高噪声环境下过早熄火**"的量化证据(p3 停在 60.2,p16 跑到 R13 已 71.8)。
**进论文**:ch3 §3.6.4 定稿 + 偏差 M-24 系补实证

### E. 变体特化画像与路由动力学 ★B2 的先验
**做什么**:(变体 × 轮次)领地大小与领地内成功率;新变体**出生簇分 vs 扩张后分**
(量化"冷启动过自信"循环);领地 churn(每轮多少题换了变体);变体存活/饿死轨迹。
**为什么值钱**:①这是我们的**独家机理观察**,论文没写过;②B2 的账本先验直接来自这里;
③解释曲线为何在无 ship 轮也能摆 ±8pp(路由重分配,不是编辑)。
**进论文**:ch7 机理讨论(主要素材)+ ch4 路由设计的实证支撑

### F. M-23 显形率
**做什么**:从 `candidate_diagnostics.archive_reason` 提取跨变体回退分类的触发计数与轮位。
**为什么值钱**:M-23 是双盲审计的三个新发现之一,且**只在 K≥2 才可能显形**;
s1k8@30 零 fork 导致显形率为 0,这次是首次真正实测。
**进论文**:附录 A M-23 行补实证 + ch3

### G. 难度分层(L1 39 / L2 52 / L3 12)★字段已核实存在
**做什么**:曲线与增益按 GAIA Level 拆分;看演化收益/退化集中在哪一层。
**进论文**:ch6 + ch7 外部效度
**限制**:L3 只有 12 题,分层后统计功效很低,只作描述不作检验。

### H. 成本账
**做什么**:逐轮/逐变体的 token、内部假价、Serper 调用、墙钟;为 B 臂的
**原始值 + 成本归一双列并报**(裁 D 的零成本补偿)备料。
**进论文**:ch5 成本口径 + ch6 表
