# 小效应检出计划

> 2026-08-03。问题：要检出 **+2~4pp**，而床的同配置重测 **SD ≈ 4.6pp**。裸比一次跑对一次跑，检不出来。
> 结论先行：**配对 + A/B 同窗交错**把噪声从 σ_D≈6.5pp 压到 ≈3.8pp（约省 2.9× 轮数），此时 +3pp 只需 ~13 个配对轮（~24h）。**33 天预算绰绰有余——前提是配对。**

---

## 0. 噪声实况（我方实测）

| 来源 | 数字 |
|---|---|
| 同池、逐字节相同配置的三次重测（e_pervar3 R3/R4/R5） | 76.7 / 85.4 / 83.5，**SD 4.59pp** |
| 同池重测间至少翻转一次的题 | **23.3%** |
| 四个独立 R0 基线点 | 64.1 / 66.0 / 69.9 / 70.9，SD 3.21pp |
| 论文自报解析二项 CI（n=103, p≈0.74） | ±8.5%（SE ≈ 4.3pp） |

**噪声分解**（由 23% 翻转率反解）：4.6pp 里约 **2.7pp 是逐题端点噪声**（不可约），其余 **1.7–3.7pp 是全局 run-level 噪声**（整轮偏好或偏坏）。

**两个后果：**
1. 我方实测 SD ≈ 论文解析二项 SE ⇒ 噪声模型基本就是二项抽样，没有额外的 harness 级方差；
2. 论文因此用**单轮** CI 去判定一个 **max-over-15-rounds** 统计量（§6.3 p.17：−24.3pp vs ±8.5%）是**错的零假设**——纯噪声下 15 轮的 E[peak−final] 约 **7–8pp**。

## ⚠ 固定 seed 几乎不省方差

**逐字节相同的重测仍然翻 23% 的题** ⇒ 端点在 temp0 下本就非确定。能锁住的是**全局分量**，办法只有**时间交错**。

---

## 1. 主设计：A/B 同窗交错配对

**做法**：`A-r1, B-r1, A-r2, B-r2, …` 在同一 endpoint session、同一工具快照下背靠背跑，让整轮的 load/state 被两臂共享而差掉。

**这就是 CRN 的有效形态**——省方差的是"同窗交错"，不是 seed。
**Antithetic** 在 LLM agent 上基本无用（控不了端点内 RNG 流），跳过。
**Control variates（免费再省 10–25%）**：把每题的历史 baseline 通过率（已有 R0 数据）当协变量做回归调整，并按 GAIA level 分层。

### 检验选型

| 检验 | 用途 | 条件 |
|---|---|---|
| **跨轮 sign-flip permutation / Wilcoxon**（对逐轮 δ̂） | **主检验** | round 当单位，自动吸收全局噪声；需 R≥6–10 |
| 配对 cluster bootstrap | **出 95% CI** | 按题（多轮再按轮）重采样、保 A/B 配对，10k 次 |
| McNemar（**精确/mid-p**） | 单个配对轮的 2×2 | discordant 仅 ~15%×103≈15 ⇒ **必须用精确二项，不能用卡方** |
| mixed-effects logistic | 多轮曲线 | `outcome ~ config + (1|question) + (1|round)`；轮数少时防不收敛 |

## 2. 离线反事实重放：有效性分界线

> **只要反事实策略仅在已落盘、未改变的 rollout 上"重新选择/重新聚合"，重放就精确有效；一旦它会改变 agent 接下来生成或观测到的东西（轨迹分叉），就必须真跑。**

**✅ 精确有效（纯 re-scoring）**
- any-k vs **all-k** vs 多数门控 → "all-k 下哪些候选会被拦"是**精确计数，不是估计**（N-02 的诊断部分）
- 精英保留的 final 分 → 有效**当且仅当**该冠军快照当时真被采样并落盘（我方满足：逐轮 `pool_state` 齐全）
- 阈值 / rerank / patience / α 的重放（N-01 读出部分、N-03、N-04）

**❌ 无效，必须真跑**
- 门控改变了下游动作（拦下某个 ship ⇒ 后续轮的 condition 变了 ⇒ 轨迹分叉）
- 此时属 OPE，需要 common support + 已知 propensity（LLM agent 基本拿不到）⇒ IPS/DR 方差大且弱

**文献立场**：Causal Agent Replay(2606.08275) 处理分叉的方式是 do-干预后**沿轨迹向前重执行**（即它重跑，不是纯重放）——正好印证纯重放只对"不分叉的 re-scoring"成立。

**三条护栏**
1. 必须有 **attempt 粒度日志**（每 attempt 的 pass/fail、分数、seed）；
2. 对会分叉的策略，**真跑一个分层小样本**，比对 replayed vs real 给偏差上界；
3. 重放数字一律标 **"re-scoring"**，不得与真跑数字并栏。

## 3. 功效与预算（80% power，α=.05 双侧）

| 真实效应 | **配对轮数** | 墙钟 | 裸比（每臂） |
|---|---|---|---|
| +2pp | **~29** | ~53h | 83 |
| +3pp | **~13** | ~24h | 37 |
| +4pp | **~8** | ~15h | 21 |

（1 配对轮 = A+B 各 103×2，交错 ≈110min。）

**够不够**：33 天里，+2pp 的 53h 全串行也只占 ~7 天；每天跑 2h、27 天即可。**预算充足——前提是配对。** 裸比则 +2pp 要 152h，才会吃紧。

**多种子 vs 多轮 = 同一根轴。** seed 已顶满且失效 ⇒ **别加种子、别把 pass@2 加成 pass@k（主读数固定）**，把预算全投**更多配对轮**。GAIA 题数封顶，所以走多轮而非扩题。

### ★ 开跑前必做：A/A 空校准

上表基于 σ_D≈3.8pp，而该值仅从 3–4 个点估出，CI 极宽。若交错只部分抵消（σ_D=5pp）轮数 ×1.7（+2pp → 49 轮）；若配对完全失效（6.5pp）→ 83 轮。

**做法**：把 baseline 当**两臂**（A=B=R0）交错跑 ~5 轮，真 δ=0。这 5 个 δ̂ 的经验 SD 就是真实 σ_D，同时验证 p<0.05 命中率 ≈5%（type-I 校准）。**成本 ~9h，一次性锁死全表**，并且这份 A/A 假阳率本身就是流程可信度的背书，可随论文一起报。

## 4. 诚实上报（防 p-hacking）

- **预注册**：开跑前把 R、主读数（配对 pass@2 的 δ）、**唯一主检验**（跨轮 sign-flip permutation）、判定阈值写死并 **git commit 打时间戳**；
- **单一主读数**：一个主终点、一个检验，其余全标 secondary/exploratory；
- **多重比较**：多臂用 Holm–Bonferroni，多子群/多变体用 BH-FDR，子群结论须独立复现；
- **报 effect size + 95% CI 而非 p**：CI 是 [0.3, 5]pp 时**不能**宣称 "+3pp"；
- **禁 optional stopping**：固定 R；必须中期看则用 O'Brien-Fleming / Pocock 边界；
- **盲分析**：两臂编码后算 δ̂，出检验后再解码；排除规则（崩溃 rollout 怎么算）预先写死。
