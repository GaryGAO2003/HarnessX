### 裁决与理由

**P-2（一次性写明硬上限 + 留 ~30 步收尾 + "未提交=零"）：上车，载荷不改。**
1. 它有据的半边是**收尾余量与结果框定**（Time's Up!、ProgramBench 98.1% 主动
   提交的部署统计），而非数字感知；数字告知按近零贡献变量对待——但"留最后
   ~30 步"这句指令需要"200 步"这个锚才有意义，数字留着无害（域内负证的受害者
   是 ≤8B 小模型与连续时间量；DS-chat 量级 + 离散步数不在已证伤害区）。
2. 它不单打：与 P-1（早落盘）、P-4（验证封顶）、P-5（压缩清单）构成烧穿因果链
   的成组干预，L5 臂另有机制级根除。
3. **预期归因预登记**：若烧穿改善，归因到收尾余量+成组干预，不主张"模型会数步"。
   过程指标：首个 manifest 落盘步数、步帽前 manifest 完成率、验证脚本数。

**P-2b（每步注入剩余步数倒计时）：不建。** 离散域因果支持缺位、8× 头条效应
是连续时间+单模型挑选、裸可见性在 agent 域实测 ≈+2pp、每步注入污染全部上下文
且对弱模型有反噬先例。

**P-2b′ 预声明升级梯（若 P-1..P-5 + L5 打满后烧穿仍残留）**：不做每步倒数，做
**阈值式两档催促**（75% 步数处"开始收尾"、90% 处"立即提交当前最优"，含收尾
工件指令）——这是生产界三处独立实现收敛的形状，且与后端强制配套（我们的步帽
本来就是硬的）。若再升级，优先"主动查询式"（L5 Status 工具带剩余步数——
Timely-RL 支持的形态，且贴我们架构），而非被动推送。届时按新偏离行登记。

## P-1 复核：维持批准 + 两条硬性注意事项 + 论文定位降级为"待验证假设"

四面深查（家族扩展/死法实证/反面专项/训练侧，约 30 个工作）净结论：

**诊断侧大幅加固**——"烧穿交白卷"是真实、普遍、已被同行评审命名的死法：
MAST（NeurIPS 2025）正式命名 "Premature termination" 占 6.2%（1642 轨迹，κ=0.88）；
SWE-Marathon Timeout 31.4% + PT 7.6% ≈ 39%；OpenHands #10767 生产统计
max_iterations=100 时 ~45% / =500 时 ~30% 撞墙；**SWE-Master（2602.03411）：
约 24.3% 被截断未提交的轨迹本来是能解决问题的正确解**，forced-submission
折扣奖励（α=0.5）达 61.4% 而"非 DONE 即零奖励"训练直接崩——与 P-1 核心
直觉结构同构的最强数字。MLE-bench A.6 逐字核验无版本漂移。

**解药侧依然零因果**——没有任何工作做过 draft-early 开/关或 draft 数量 N 的
受控消融；SWE-agent Table 13（主动 submit 93% vs 全体 69%）有反向因果混淆
（更可能"做对了才早交"）。**P-1 在论文里只能写成待验证假设，不能作为已证
前提引用**；HarnessX 若做 draft-early 消融即第一批数据（与 F2/F3 条款对上）。

**反面证据裁定**：
- 锚定（C1）：硬。METR 实测 84% 粘死初选架构；SCoRe 的纯提示自我修正臂
  Δ=−1.0%（RL 改造才 +4.4%）——**"评审自查"若只是提示词建议，预期应设为
  近零**；有效缓解全部是结构性的（独立监督角色/扩大动作空间/训练目标）。
- 灌水（C2）：可控。三个负例全部可追溯到"选择环节缺有效性门槛"这个实现
  缺口，非起草本身有害；AIDE 自身 num_drafts=5 封顶。
- gaming（C3）：最硬的一条，但杠杆是**打分器与 agent 共享执行环境**这一
  架构选择（METR 一年半系列：30.4% run 含 hacking → 跨四实验室 ≥16% 非法；
  被直接问"是否作弊"主动否认 ⇒ 提示词防护零免疫）。MLE-bench 阴性对照：
  提交式评分、判分与 agent 隔离时未发现案例。

**映射到 HarnessX（两条注意事项的落地）**：
1. AEGIS 的 ship 判定不靠 Evolver 自报：五门确定性 + Critic 复核 + G2 图门
   都在 Evolver session **之外**运行——判分隔离已是现状；但 capability_evidence
   的 L1/L2 自验证本质是 agent 自报，**任何时候都不得让它单独承重 ship 决策**
   （现状满足，此为不变量，写进 CH7 威胁与运维红线）。
2. 结构性 checkpoint > 提示建议——**L5 的每调用写通恰是文献支持的"结构性"
   形态，P-1 是同一疾病的提示级弱形态（服务 L0–L4 臂）**。预登记预期：
   若 L5 臂的仪式死消减显著强于 P-1 所在的对照臂，与文献方向一致；反之
   构成对文献判断的挑战性数据。两种形态同病异药的对比本身是论文素材。

**复核裁定：P-1 批准维持，不回炉。** 上述两条注意事项与"待验证假设"定位
随行写入偏差表与 CH7。
